# E1.3 — the accessor set

`Symlinker`, `Streamer` and `Truncater` as narrow interfaces in
`internal/core/vfs`, reached through `AsSymlinker`, `AsStreamer` and
`AsTruncater` on `FileSystem`, with `NoCaps` as the embeddable refusal of all
three.

## What the pattern was

The settled decision, made concrete: optional verbs live behind accessors on the
base interface, never behind a type assertion. A plugin embeds `NoCaps` and
overrides only the accessors it answers.

## What surprised me

**The accessors belong on `FileSystem`, and that is the whole mechanism.** They
read like a convenience over `fs.(Symlinker)` and are not. Every caller holds
the mount dispatcher, so an assertion asks the wrapper whether it can make
symlinks — a question the wrapper cannot answer for the plugin behind it. A
method on the base interface leaves the dispatcher no choice but to forward.
`http.ResponseController` exists because the standard library learned this late.

**`NoCaps` returns an untyped nil, and the type of that nil is load-bearing.**
The caller's contract is `if s := fsys.AsStreamer(); s != nil`. A plugin that
returns `(*myStreamer)(nil)` from its accessor hands back an interface that is
not nil, and the guard admits a value that panics on first use. `NoCaps` cannot
make that mistake — it has no pointer type to return — but an overriding plugin
can, so the constraint is written down where the override is.

**`Streamer` is two verbs, not a handle.** E1.7 skips stateful open handles in
the port; the streams are `io.ReadCloser` and `io.WriteCloser`, which the caller
owns and closes, and the plugin holds no open state between calls.

## What I would do differently

`NoCaps` is named for capabilities and currently refuses only accessors. E1.2's
descriptors have no default yet. If a plugin should be able to say nothing about
itself at all, that default belongs on this same struct, and the name is already
right for it.

## What I still do not understand

Whether `Truncater` earns a place beside `Streamer`. Truncate to zero is
`Write(path, nil)`, and truncate to a length is a read-modify-write on anything
that is not a disk. The roadmap fixes the accessor, so it stays; E2.4's object
store is where it either pays for itself or turns out to be a disk verb wearing
a port's clothes.

Whether an accessor per optional verb set scales past three. Four is fine; a
dozen is a wide interface every plugin embeds `NoCaps` to ignore.
